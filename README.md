Secure Ethereum-enabled execution framework for EVM-compatible smart contracts with optimized performance and scalability.

With SolidityStackPlus, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/SolidityStackPlus.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure SolidityStackPlus, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
